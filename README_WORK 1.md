## 1. Код из выдачного материала (код на ревью)

```py
def can_buy(age):
    if age > 18:
        return "да"
```
2. Отчёт по ревью
1. Что требует ТЗ
Функция can_buy(age):

принимает возраст (целое число);
возвращает True, если возраст 18 и больше;
возвращает False, если меньше 18.

2. Что код делает на самом деле
Код проверяет только условие age > 18.

Если возраст больше 18 — возвращает строку "да".

Если возраст 18 или меньше — ничего не возвращает (None).
3. Несоответствия

В ТЗ «18 и больше» (>= 18), в коде стоит > 18. В 18 лет не пройдёт.
Нужны True/False, а возвращается текст "да".
Нет return False для возраста меньше 18.
Нет проверки, что age — число.

4. Вердикт
отклонить
5. Что исправить
Писать age >= 18, возвращать True/False, добавить ветку для возраста меньше 18.
def can_buy(age):
    if age >= 18:
        return True
    return False
