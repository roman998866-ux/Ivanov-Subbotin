## 1. Код из выдачного материала (код на ревью)

```py
def is_pass(score):
    if score >= 60:
        print("зачёт")
```
2. Отчёт по ревью
1. Что требует ТЗ
Функция is_pass(score):

принимает баллы (число);
возвращает True, если баллов 60 и больше;
возвращает False, если меньше 60.

2. Что код делает на самом деле
Код проверяет условие score >= 60.

Если баллов 60 и больше — печатает строку "зачёт".

Если меньше 60 — ничего не делает.

Функция ничего не возвращает (всегда None).
3. Несоответствия

По ТЗ нужно возвращать True/False, а код печатает текст "зачёт".
Нет return True при score >= 60.
Нет return False при score < 60.
Функция вообще ничего не возвращает.

4. Вердикт
отклонить
5. Что исправить
Убрать print, возвращать True если score >= 60, иначе возвращать False.
def is_pass(score):
    if score >= 60:
        return True
    return False
