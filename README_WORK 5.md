## 1. Код из выдачного материала (код на ревью)

```py
def need_jacket(temp):
    if temp < 10:
        return False
```
2. Отчёт по ревью
1. Что требует ТЗ
Функция need_jacket(temp):

принимает температуру воздуха;
возвращает True, если температура ниже 10;
возвращает False, если 10 и выше.

2. Что код делает на самом деле
Код проверяет условие temp < 10.

Если температура ниже 10 — возвращает False.

Если температура 10 и выше — ничего не возвращает (None).
3. Несоответствия

Логика перевёрнута: при температуре ниже 10 возвращает False, а должен True.
Нет return False для температуры 10 и выше.
Функция не возвращает ничего, если temp >= 10.

4. Вердикт
отклонить
5. Что исправить
При temp < 10 возвращать True, иначе возвращать False.
def need_jacket(temp):
    if temp < 10:
        return True
    return False
