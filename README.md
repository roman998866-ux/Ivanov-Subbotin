## 1. Код из выдачного материала (код на ревью)

```python
def is_strong(password):
    if len(password) > 8:
        return True
---


Функция is_strong(password):
- принимает строку пароля;
- возвращает True, если длина пароля не меньше 8 символов;
- возвращает False, если длина меньше 8.

Код проверяет только условие len(password) > 8.
Если длина больше 8 — возвращает True.
Если длина 8 или меньше — ничего не возвращает (None).

- В ТЗ «не меньше 8» (>= 8), в коде стоит > 8. При длине ровно 8 не пройдёт.
- Нужны True/False, а при длине ≤ 8 ничего не возвращается.
- Нет return False для пароля короче 8 символов.

отклонить

Заменить условие на len(password) >= 8, всегда возвращать True или False.

```python
def is_strong(password):
    if len(password) >= 8:
        return True
    return False
